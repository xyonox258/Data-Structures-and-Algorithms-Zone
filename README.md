# Data Structures and Algorithms Zone (DSA Zone) 🚀

Welcome to the **DSA Zone**! This repository is a collection of core Data Structures and Algorithms implemented entirely from scratch using **pure C** inside the Dev-C++ environment. 

Unlike standard theoretical code snippets, the implementations here are designed as interactive, menu-driven command-line (CLI) tools. You can interactively trigger operations like Push, Pop, Insertion, and Deletion right inside your terminal to see how data and memory pointers behave in real-time.

---

## 📂 Inside the Zone

This repository features standalone, interactive implementations of fundamental data structures:

- **📁 Stack (`stack.cpp` / `stack.c`):** An interactive Last-In-First-Out (LIFO) simulator featuring live terminal menus for dynamic `Push` and `Pop` operations with real-time stack state printing.
- **📁 Queue (`queue.cpp` / `queue.c`):** A clean First-In-First-Out (FIFO) structural implementation supporting core `Enqueue` and `Dequeue` operations.
- **📁 Linked List (`linked_list.cpp` / `linked_list.c`):** A pointer-heavy dynamic memory implementation demonstrating node creation, targeted index insertion, and runtime element deletion.

---

## 🛠️ How to Compile & Run

Every file in this zone is independent and written with pure C logic. You can easily compile and run them using any standard C/C++ compiler (like GCC inside Dev-C++ or terminal).

Choose the file you want to explore and run the following commands in your terminal:

```bash
# Example: To compile and run the Stack implementation
gcc stack.cpp -o stack
./stack
```

## 🧠 Why This Repository Exists

Mastering pointers, memory tracking, and low-level manual memory allocation is one of the hardest parts of computer science. This repository serves as a practical sandbox to bypass textbook abstractions and master the underlying mechanics of low-level software engineering.
